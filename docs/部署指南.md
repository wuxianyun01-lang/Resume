# 吴志勇简历网页版部署指南

本指南不需要会 Git、不需要写代码，跟着浏览器操作即可。

## 方式一：Netlify Drop（最快，推荐先用这个）

1. 用浏览器打开：<https://app.netlify.com/drop>
2. 第一次使用会让你登录，选择“使用 GitHub 登录”或“使用邮箱登录”都可以。
3. 登录后把 `WZY-Resume-Web` 文件夹直接拖进网页中间的上传区域。
4. 等待几秒，页面出现 `https://xxxx.netlify.app` 就是你的简历链接。
5. 复制这个链接发给 HR 即可。

> 拖进去的必须是文件夹，里面包含 `index.html` 和 `assets` 文件夹，不能只拖一个 HTML 文件。

## 方式二：GitHub Pages（永久链接，适合长期维护）

### 第 1 步：新建 GitHub 仓库

1. 打开 <https://github.com>，注册或登录账号。
2. 点右上角 `+`，选择 `New repository`。
3. Repository name 填：`resume`
4. Visibility 选择 `Public`（免费账号的 Pages 需要公开仓库）。
5. 不要勾选 `Add a README file`，直接点 `Create repository`。

### 第 2 步：上传网页文件

1. 先在本机解压 `吴志勇-IT运维工程师-网页版部署包.zip`，得到一个文件夹。
2. 打开文件夹，里面应该有：
   - `index.html`
   - `assets` 文件夹
   - `.github` 文件夹
   - `README.md`
3. 回到刚创建的 GitHub 仓库页面，点 `Add file` -> `Upload files`。
4. 把上面这几个文件和文件夹一起拖进上传区域。
5. 点绿色按钮 `Commit changes`。

### 第 3 步：打开 GitHub Pages

1. 进入仓库页面顶部的 `Settings`。
2. 左侧找到 `Pages`。
3. `Build and deployment` 的 `Source` 选择 `GitHub Actions`。
4. 保存后，等 1 到 2 分钟。
5. 刷新 `Actions` 标签页，看到绿色对勾就说明发布成功。

### 第 4 步：找到链接

链接格式为：

```text
https://你的GitHub用户名.github.io/resume
```

例如用户名是 `wuzhiyong`，链接就是：

```text
https://wuzhiyong.github.io/resume
```

## 发布后如何修改

每次修改网页内容后，重新生成部署包，再重复上面的上传步骤即可。

## 常见问题

### 打开网页后照片不显示

说明只上传了 `index.html`，`assets` 文件夹没有一起上传。请重新上传整个部署包内容。

### 上传后还是旧版本

浏览器可能缓存了旧页面，按 `Ctrl + F5` 强制刷新。

### GitHub Pages 显示 404

检查仓库是否 Public，以及 Settings -> Pages 的 Source 是否选择了 `GitHub Actions`。
